## Source boundaries

Memory is an authenticated current-user field projection, with deterministic scoped field IDs. The source model lacks per-entry provenance, approval, status and timestamps; seeded defaults cannot be separated from supplied values. Never infer these properties. Sources are department/oversight/branch instruction graph nodes and the explicitly exposed company constitution. Developer handoff, state, PRODUCT, DESIGN and ROADMAP stay excluded, including relationship targets. Graph IDs and actual links are preserved. Modified refers only to valid source file modification time. No protected normalized Knowledge, Decisions, Archive or complete loaded-context manifest exists. Existing NORA surface/selected-record context is observable, but does not establish a full Active Context stack.
